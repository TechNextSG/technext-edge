Các Lỗi Kỹ Thuật Thật Đã Bắt & Khắc Phục Trong PodReal Technical Defects Caught & Hardened in Pod

Nhờ chạy thử nghiệm thực tế với máy chấm tự động, pod đã phát hiện và xử lý triệt để 4 lỗi kỹ thuật nghiêm trọng: Through automated dry-runs against live providers, the pod caught and fixed 4 critical issues:

BUG-EXT-01 (Nghiêm trọng) — Lỗi Hạn ngạch 429 bị báo nhầm thành Lỗi Validation Schema 422: BUG-EXT-01 (Critical) — Rate Limit 429 Erroneously Reported as Schema Validation 422: Khi gọi Gemini bị cạn quota free-tier (HTTP 429), pipeline cũ bắt lỗi chung và gói lại thành ExtractionValidationError (422), làm người kiểm thử tưởng nhầm mô hình sinh sai định dạng. Đã sửa: Phân tách rạch ròi HTTP 429/502 cho lỗi hạ tầng mạng và 422 cho lỗi vi phạm Zod schema. Free-tier Gemini quota rate limits (HTTP 429) were erroneously caught and wrapped into ExtractionValidationError (HTTP 422), misleading testers into thinking the model failed schema constraints. Fixed: Distinct handling separating infrastructure 429/502 from schema 422 errors.
BUG-EXT-02 (Lớn) — DeepSeek Gateway từ chối Boolean Bounds với lỗi 400: BUG-EXT-02 (Major) — DeepSeek Gateway Rejects Boolean Bounds with HTTP 400: Hàm zod-to-json-schema sinh ra exclusiveMinimum: true cho các trường số nguyên dương. Validator của DeepSeek chỉ chấp nhận dạng số nguyên mới và trả về lỗi 400 Bad Request. Đã sửa: Viết hàm toDeepSeekSchema() tự động lọc bỏ các bound boolean trước khi gửi sang gateway. zod-to-json-schema emitted exclusiveMinimum: true for positive integers, which DeepSeek's strict validator rejected with HTTP 400. Fixed: Implemented toDeepSeekSchema() stripping unsupported boolean bounds.
BUG-EXT-03 (Vừa) — Máy Chấm Điểm Đếm Nhầm Giá Trị Mặc Định Thành "Bịa Đặt": BUG-EXT-03 (Medium) — Eval Harness Miscounted Villa Defaults as "Hallucinations": Trong đợt dry-run đầu tiên, bộ chấm điểm đếm giá trị phòng mặc định từ houseNorms.ts là lỗi hallucination vì tin nhắn khách không đề cập số phòng. Đã sửa: Cập nhật scorer để phân biệt rõ giá trị do hệ thống gán mặc định (default) với giá trị do model tự bịa đặt. Early eval harness runs miscounted villa house-norm defaults as hallucination because the guest didn't explicitly mention room counts. Fixed: Scorer updated to differentiate legitimate villa default states from model fabrications.
BUG-EXT-04 (Vừa) — DeepSeek Gateway Treo Vô Tận & Bị Trễ Do Thinking Mode: BUG-EXT-04 (Medium) — DeepSeek Gateway Hung & Incurred High Latency from Thinking Mode: DeepSeek qua gateway bị xung đột khi vừa bật chế độ suy nghĩ (thinking mode) vừa ép tool_choice, gây trễ lên tới 16 giây hoặc treo request. Đã sửa: Bổ sung thinking: { type: "disabled" } và gán AbortController timeout 20s bảo vệ. DeepSeek gateway calls conflicted between enabled thinking mode and forced tool_choice, driving latency to 16s or hanging indefinitely. Fixed: Enforced thinking: { type: "disabled" } and wrapped calls in a 20s AbortController timeout.
